# Radar de Oportunidades com IA

## Instalar no Codex para teste VIP

```bash
codex plugin marketplace add "$HOME/Downloads/radar-de-oportunidades-release"
codex plugin add radar-de-oportunidades@radar-de-oportunidades
```

Feche completamente o Codex e abra novamente. Em uma nova tarefa, peça:

> Use o Radar de Oportunidades com meu Dossiê de Mercado para encontrar empresas alinhadas ao meu público ideal.

## Entrega da versão beta

O plugin trabalha em modo de pesquisa pública e entrega:

- `RADAR-DE-OPORTUNIDADES.md`;
- `LEADS-QUALIFICADOS.csv`;
- evidências e nível de confiança;
- abordagem sugerida apenas como rascunho.

Ele não envia mensagens, não preenche formulários e não acessa dados privados.
